# 까망 점집 — 안내 사이트

이 사이트는 스토어 안내 · 이용약관 · 개인정보 처리방침 · 환불 안내 · 사업자 정보만 둡니다. GitHub Pages로 공개합니다.

- `privacy.html`, `terms.html`, `refund.html`, `business.html`: 플레이 콘솔·앱스토어와 앱 안(홈 아래 링크)에서 링크하므로 **지우거나 옮기지 말 것**
- 원본은 `ghdakrk/cardgame` 저장소의 `site/` 폴더다. 고칠 때는 원본을 고친 뒤 이 저장소에 복사한다
- 처리방침을 바꾸면 시행일과 변경 내용을 페이지에 적고, 앱이 보내는 정보가 바뀌면 플레이 콘솔 「데이터 보안」 답도 같이 고친다
- `try/`: 가족·지인 체험판 내려받기 안내(검색 노출 안 함). `try/kkamang-trial.apk`는 원본 저장소에 두지 않고 이 공개 저장소에만 올린다. 다시 만들 때: 원본 저장소에서 `sh app/scripts/build-trial.sh` → APK를 `try/`에 복사 → `try/index.html`의 SHA-256을 바꾼다
